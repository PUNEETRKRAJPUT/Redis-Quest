## Surprises
- The legacy `styles.css` has an unlayered `.sr-only` that beats Tailwind's layered `sr-only` and `focus:not-sr-only`. The skip link therefore parks itself with a translate instead. Anything else that needs "visible on focus" cannot use `sr-only` either.
- Playwright's `press('Shift+/')` sends key `/`, not `?`; use `press('?')`. Real keyboards send `?`.
- A layout-level `<ViewTransition>` does animate: not through enter/exit (layouts persist) but through `update` keyed by a transition type. React names the pseudo-elements itself (`_t_0_`), so the CSS targets the class (`.rq-fade`). The root snapshot must be switched off (`::view-transition-old/new(root) { animation: none }`) or the HUD cross-fades with the page. Under reduced motion the selectors must be `:root[data-motion='reduce']::view-transition-old(...)` without a space (the pseudo-elements hang off the root element).
- The unlayered `:focus-visible` ring beats `outline-none` utilities; the palette input removes it with an inline style and marks focus on its row instead.
- Fast Refresh from other agents' edits can fail a vitest run or remount a page mid-test once in a while; rerun.

## What the integration task and other screens must know
- **New test ids:** `score-plate` (the HUD plate, a link to /built), `rain-delay`, `play-resumes`, `rain-command`. No id or text was removed or renamed.
- **Layout contract:** the shell is `<div class="flex min-h-dvh flex-col">`; `#main` is `flex-1 min-h-0`. The sticky chrome (HUD, plus the rain strip and mirror banner while they show) sets `--hud-h` on `<html>` (56px, more while a strip shows). A full-height screen can use `h-[calc(100dvh-var(--hud-h))]`. `#main` has no `data-ds` on purpose: that would revert the legacy element rules for screens not yet rebuilt.
- **Links:** QuestLink and the palette and shortcuts pass the transition type `rq-nav`; a plain `next/link` still navigates, just without the cross-fade.
- **Palette data:** it reads `useQuest().chapters`; new chapters and levels appear without a change. Level rows are `Command.Item`s with `disabled` when `status === 'locked'`.
- **If you add a screen** to the HUD, add it to `NAV` in `ui/src/shell/nav.ts` (one place feeds HUD, palette, shortcuts and the sheet); pick an unused letter.
- Ctrl+K inside the terminal is left to the shell's own "kill line"; Cmd+K works there.
- No change needed in any file I do not own. No dependency added (cmdk, motion, lucide-react were already in package.json). No commit, no `docs/BUILD.md` edit.
