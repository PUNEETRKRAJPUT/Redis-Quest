### Where the trace lives
The per-request counting is in `@quest/shared`, which this task does not own. The trace therefore wraps the
already counted deps in the app (`app/src/trace.ts`) and uses the counters themselves to decide what is a command
(a call that moved `counters.redisCommands` is one), so there is no second list of command names and no second
counting mechanism. It is only built when the request carries `x-quest-trace: 1`.
