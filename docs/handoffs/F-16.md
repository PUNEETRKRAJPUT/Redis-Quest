## Cookbook for the screen tasks

**Import:** `import { Button, Panel, toast, play, celebrate } from '@/design';`

**Mount the runtime once.** `<DesignRuntime>` hydrates saved settings, writes `<html data-motion="full|reduce">`,
unlocks audio on the first gesture, sets motion's `MotionConfig`, and hosts `Toaster`, `Confetti`, `Floodlights`.
Today only the gallery mounts it (I may not touch the layout); see "What the orchestrator needs" below.

**Wrap redesigned screens in `data-ds`.** The legacy `styles.css` is unlayered and its `h1/h2/h3/p/a/code/pre`
rules beat every Tailwind utility (utilities live in a cascade layer). Inside any element with `data-ds` (every
primitive root carries it) those legacy element rules are reverted (`revert-layer`), so utilities work. Put
`data-ds=""` on the root of each rebuilt screen.

**Tokens / utilities** (Tailwind's default palette and scale are removed on purpose):
- Colours: `night-950/900/800/700/600`, `chalk`, `chalk-dim`, `chalk-faint`, `flood-400/500/600`, `on-flood`,
  `turf`, `wicket`, `sky`, `cap-purple` (+ `white`, `black`, `transparent`, `current`). Opacity works: `bg-turf/10`.
  `chalk-faint` is for disabled/decorative text only (4.47:1 on night-900, 4.1 on night-800).
- Fonts: `font-display` (Barlow Condensed), `font-sans` (Inter), `font-mono` (JetBrains Mono).
- Text: `text-xs` 12, `text-sm` 13, `text-md` 14 (UI), `text-base` 16 (lesson), `text-lg` 18, `text-xl` 22,
  `text-2xl` 28, `text-3xl` 40, `text-4xl` 64.
- Radii `rounded-xs/sm/md/lg/xl/full` (4/6/10/14/20). Shadows `shadow-hairline`, `shadow-raise`, `shadow-pop`,
  `shadow-glow`, `shadow-glow-turf`, `shadow-glow-wicket`.
- Motion: `ease-out-expo` (the brief's `out`), `ease-in-out`, `ease-snap`; `duration-instant/fast/base/slow/celebrate`
  (90/150/220/400/900ms); `animate-spin`, `animate-live` (status light pulse), `animate-shimmer`, `animate-typing`.
- Helpers: `label-caps` (scoreboard label), `tabular` (tabular numerals), `rule-fade` (fading 1px divider).
- `motion-ok:` variant: use for every translate/scale/rotate, e.g. `motion-ok:hover:-translate-y-0.5`.
  Add class `ds-still` to anything with a keyframe animation that must stop under reduced motion.
- CSS variables exist for everything (`var(--color-flood-500)`, `var(--duration-base)`, ...).
- Legacy variables (`--bg`, `--surface`, `--ink`, `--accent`, `--ok`, `--bad`, `--mono`, `--sans`, all 22) are
  re-declared, so un-ported markup already wears the palette and fonts.

**Primitives (all accept `className`; no tailwind-merge is installed, so a passed class does not reliably override
a conflicting internal one: wrap or extend instead of fighting)**
- `Button` `{ variant?: 'primary'|'ghost'|'quiet'|'danger'; size?: 'sm'|'md'|'lg'; loading?; loadingText?;
  leading?; trailing?; shortcut?: string }` + all button attributes. `type="button"` by default. Loading = spinner,
  `aria-busy`, disabled, keeps width (or shows `loadingText`, e.g. "Decision pending").
- `IconButton` `{ label (required, accessible name + tooltip); icon; tooltip?: boolean; variant?; size? }`.
- `Tooltip` `{ content; children: one focusable element; side?: 'top'|'bottom'; delay?=350; describe?=true; shortcut? }`
  shows on hover (delayed) and keyboard focus (at once), Escape hides.
- `Kbd` `{ children; size?: 'sm'|'md' }` one key per Kbd.
- `Switch` `{ checked; onCheckedChange; label; hideLabel? }` (`role="switch"`).
- `Segmented<T>` `{ options: {value,label}[]; value; onValueChange; label; size? }` (radiogroup, arrow keys).
- `Tabs` `{ items: {id,label,icon?,badge?,content}[]; label; value?; defaultValue?; onValueChange? }`
  WAI-ARIA tabs, arrows/Home/End, automatic activation, plays `tick`.
- `Card` `{ tone?: 'base'|'raised'|'inset'; interactive?; focal? (the one loud thing); padding?: 'none'|'sm'|'md'|'lg' }`.
- `Panel` `{ title; eyebrow?; icon?; actions?; footer?; as?: 'h2'|'h3'|'h4'; bodyClassName? }` + Card props.
- `Pill` `{ tone?: 'neutral'|'flood'|'turf'|'wicket'|'sky'|'cap'; variant?: 'status'|'tag'; live?; icon?; size? }`.
- `Dialog` `{ open; onClose; title; description?; children?; footer?; size?: 'sm'|'md'|'lg'; tone?: 'default'|'danger' }`
  on native `<dialog>.showModal()` (focus trap, inert page, Escape, focus returns to the trigger; verified).
- `ProgressBar` `{ value? (omit = indeterminate); max?; label; showLabel?; valueText?; tone?; size? }`.
- `Meter` `{ value; min?; max?; label; valueText?; warnAt?=0.7; dangerAt?=0.9; segments?=24 }` (`role="meter"`).
- `Skeleton` `{ className? (sizes it); lines?; label? }`. `EmptyState` `{ icon?; title; children?; action? }`.
- `FlipNumber` `{ value; minDigits?; size?: 'sm'|'md'|'lg'|'xl'; sound?=true; label?; tone?: 'chalk'|'flood'|'turf' }`
  split-flap 3D flip per changed digit, units first, `flip` cue per digit (max 4); screen readers get one polite text.
- `Scoreline` `{ label; value: number|string; unit?; flip?; minDigits?; delta?; size?; tone?; hint? }`.

**Toasts:** `toast('Saved')`, `toast({ title, description?, tone?: 'info'|'success'|'warn'|'error', duration?,
action?: { label, onClick }, cue? })`, `toast.success/error/warn(title, description?)`, `toast.dismiss(id)`.
Max 4 on screen; pause on hover/focus; errors are `role="alert"` and stay 7s.

**Sound:** `play(cue)` with `'tick'|'msg'|'tock'|'out'|'flip'|'roar'|'pager'`; returns false and does nothing while
`useSettings` has `sound: false` (the default) or WebAudio is missing. The AudioContext is created on the first
gesture after sound is on. `CUES[cue]` documents meaning, sound and duration (all under 1.5s).

**Celebration:** `celebrate({ cue?: 'tock'|'roar', confetti?: {x,y,count,spread} })` = `floodlights()` +
`confetti()` + `play('tock')`. Flip the XP yourself (`<FlipNumber value={xp} />` re-renders).

**Motion:** `DURATION` (s), `DURATION_MS`, `EASE_OUT`, `SPRING.flip/card/pop`, variants `fade`, `rise`, `pop`,
`list` + `listItem` (pass `custom={index}`; 30ms stagger capped at 10). Use `variantsFor(rise, useReducedMotion())`
or rely on `DesignRuntime`'s `MotionConfig`.

**How reduced motion is resolved:** `useSettings().reducedMotion` is `'system' | 'on' | 'off'`;
`resolveReducedMotion(setting, osPrefersReduced)` — `on` always reduces, `off` never, `system` follows
`prefers-reduced-motion`. `useReducedMotion()` (React) and `isReducedMotionNow()` (imperative) apply it; the runtime
mirrors it to `html[data-motion]`, which CSS (`motion-ok:`, `.ds-still`, dialog, floodlights) reads; before the
runtime runs CSS falls back to the OS media query. Reduced = no translate/scale/flip/confetti, fades ≤150ms, the
floodlight sweep becomes a soft wash.

**Settings:** `useSettings` (zustand, persisted to `localStorage['rq:settings']`, `skipHydration` so the server and
first client render agree; `hydrateSettings()` is called by the runtime). Actions: `setSound`, `toggleSound`,
`setVolume` (clamped 0..1), `setReducedMotion`.

## Surprises
- Unlayered legacy CSS beats layered Tailwind utilities regardless of specificity, hence `data-ds` + `revert-layer`.
- motion (v14) animates transform/opacity through WAAPI: inline `style.transform` does not change mid-animation;
  sample `getComputedStyle` when testing.
- Dev server logs an instant-navigation "dropped segment" error for every route under `GameShell`; `instant = false`
  silences it for `/design`. Motion logs a dev warning when reduced motion is on; harmless.
- next/font names each family after its `const`, so the constants are named `barlowCondensed`, `inter`,
  `jetbrainsMono`.
