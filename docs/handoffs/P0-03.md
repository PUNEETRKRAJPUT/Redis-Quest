Wrote `docs/fiction.md` (league, 8 franchises, origin story, cast, tone guide, naming rules, id scheme), seven JSON
files under `fiction/` (league, teams, players, colleges, hostels, cast, denylist) and `scripts/check/P0-03.sh`.

more than 3 times. Denylist: 481 real cricketers (all eras and nations), 63 real franchises across IPL, BBL, PSL, CPL,
SA20, The Hundred and ILT20. The generator script lived in the scratchpad, not the repo.

## What I did not do

## What surprised me
- The denylist's own surnames (Sharma, Singh, Khan, Patel, Yadav, Kumar, Iyer, Reddy, Nair...) are the most common
  Indian surnames, so excluding them entirely removed a lot of the natural pool. The fiction is better for it.
- Spec says "nickname for about one in five": exactly 40 of 200 have one, including the three stars.

## For P0-04 (Postgres seed)
Every file is an object with one array key. Read with `JSON.parse`; ids are stable strings.
- `teams.json` -> `{teams:[{id,name,city,code,primary_colour,secondary_colour,home_ground,personality}]}`
- `players.json` -> `{players:[{id,name,team_id,role,batting_hand,bowling_style|null,age,bat_avg,strike_rate,bowl_econ|null,bowl_avg|null,nickname|null,fame}]}`
  role in batter|bowler|all-rounder|keeper; batting_hand in left|right; batters and keepers have bowling_style, bowl_econ and bowl_avg all null.
  bat_avg, strike_rate, bowl_econ, bowl_avg are JSON numbers (use NUMERIC, not INT). fame is an integer 1 to 100.
  The three stars (fame above 95): p-028 (99), p-101 (97), p-151 (96). Players are in team order, 25 per team.
- `colleges.json` -> `{colleges:[{id,name,short,city,state,founded,mascot,story_role|null}]}`; story_role is "home" (c-02) or "rival" (c-06) or null.
- `hostels.json` -> `{hostels:[{id,college_id,name,kind(boys|girls),capacity}]}`; id format h-c-NN-n.
- `cast.json` -> `{cast:[{slug,name,nickname,role,college_id|null,bio,dialogue:[{time,text}]}]}`
- `league.json` is a single object (name, short, season, format, final); not a seed table, for UI strings.
- `denylist.json` -> `{cricketers:[...],franchises:[...]}`; do not seed it.
Keys prefixed with an underscore (`_note`) are comments; ignore them.
