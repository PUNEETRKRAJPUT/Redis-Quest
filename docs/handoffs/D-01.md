## How to verify
stack.mjs (needs a Mac or Linux box with Node 22, built packages, a Redis and a seeded Postgres; use throwaway
containers that are NOT the compose project, on other host ports):

    docker run -d --name d01-redis -p 127.0.0.1:6391:6379 redis:8
    docker run -d --name d01-pg -p 127.0.0.1:5491:5432 -e POSTGRES_USER=quest -e POSTGRES_PASSWORD=quest -e POSTGRES_DB=quest postgres:16
    # load the seed as ci.yml does (psql ... -f postgres/init/001-schema.sql, gunzip -c 002-seed.sql.gz | psql, 003, 004)
    pnpm -r build
    REDIS_URL=redis://127.0.0.1:6391 DATABASE_URL=postgres://quest:quest@127.0.0.1:5491/quest STACK_PORT=3591 node scripts/ci/stack.mjs
    curl -s localhost:3591/health ; curl -s localhost:3591/app/health      # then Ctrl-C
    docker rm -f d01-redis d01-pg
    node --test scripts/ci/stack-lib.test.mjs
