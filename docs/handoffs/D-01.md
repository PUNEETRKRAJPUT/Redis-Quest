## How to verify
stack.mjs (needs a Mac or Linux box with Node 22, built packages, a Redis and a seeded Postgres; use throwaway
containers that are NOT the compose project, on other host ports):

    docker run -d --name d01-redis -p 127.0.0.1:6391:6379 redis:8
    docker run -d --name d01-pg -p 127.0.0.1:5491:5432 -e POSTGRES_USER=quest -e POSTGRES_PASSWORD=quest -e POSTGRES_DB=quest postgres:16
    # load the seed as ci.yml does (psql ... -f postgres/init/001-schema.sql, gunzip -c 002-seed.sql.gz | psql, 003, 004)
    pnpm -r build
    REDIS_URL=redis://127.0.0.1:6391 DATABASE_URL=postgres://quest:quest@127.0.0.1:5491/quest STACK_PORT=3591 node scripts/ci/stack.mjs
    curl -s localhost:3591/health ; curl -s localhost:3591/app/health      # then Ctrl-C
    docker rm -f d01-redis d01-pg
    node --test scripts/ci/stack-lib.test.mjs

## Decisions and surprises
- Deterministic mode skips every level with a traffic verifier, not only latency/baseline ones. Reason: even the
  count assertions (`db_queries_lte`, `hit_ratio_gte`, `error_rate_lte`) depend on how much load a 2-vCPU runner
  can generate in the run window. Cheap to loosen later in `scripts/ci/deterministic.mjs` (one function).
- Random interview pool levels (finale) are skipped: the draw can land on a traffic level.
- The helper lives in `scripts/ci/` (a folder this task owns) rather than `scripts/grade/`, which D-01 only
  owns through `grade.mjs`.
- `stack.mjs` applies the compose Redis settings (maxmemory 512mb, noeviction, save 60 1000, AOF everysec) with a raw
  RESP socket, because a CI `redis:8` service container starts bare and the grader resets exactly those after
  `CONFIG SET` levels. No `redis` package import, so no dependency.
- `SECURITY.md` does not invent a contact address: it points at GitHub's private "Report a vulnerability" button
  if enabled, else a content-free public issue. The maintainer checklist (at the end) enables the button.
- `CONTRIBUTING.md` and `SECURITY.md` describe the `pr-verdict` workflow and `scripts/review-pr` in words only;
  they are true once those land (they are on this branch).
