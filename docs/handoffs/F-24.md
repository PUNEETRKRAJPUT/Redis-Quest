# F-24 handoff: tools pages and the career page

## What I built
- **Editor** (`EditorPanel`, `MonacoEditor`): grouped file tree, open-file tabs with per-file buffers (unsaved edits survive switching;
  closing a dirty tab asks in a Dialog), breadcrumb bar with a status line ("unsaved changes" / "Saved <path>"), Save button
  (tooltip with the Cmd+S hint), Cmd+S from anywhere in the panel, status footer (Ln/Col, language, VS Code hint).
  Monaco theme `quest-night` (data in `ui/src/career/tools/monacoTheme.ts`, literal hex from tokens.css, checked by a test): amber
  cursor and selection, sky find matches, readable syntax colours, JetBrains Mono, re-measured when the font loads. A model per
  file path. Two fixes found on the way: Cmd+S inside Monaco saved the text from mount time (now a ref), and a lagging render could
  hand Monaco an older value and drop or double typed characters (the editor now only receives a new `value` when the text changed
  from outside). Worker creation and lazy loading are untouched.
- **Logs**: service tabs (`role="tab"`, names kept) with error-count badges, level filter (All/Warnings/Errors), text filter, Follow
  switch, error and warning rows tinted with a rail, click or arrow keys to inspect the raw line (pretty JSON, copy). Lines are
  parsed per dialect (pino, Caddy access log, Postgres text) and cached. Rendering is windowed by hand (fixed 28px rows, about 25 in
  the DOM for 1000 lines). Scrolling up pauses, "N new lines: jump to live" resumes, End also resumes.
- **Metrics**: scoreboard tiles (`metrics`, `metric-<label>` incl. `metric-p99`), flip digits for counts, sparkline with area and
  last-point dot, avg and peak. `Sparkline` keeps its props (F-23's show-me uses it) plus optional `tone`, `focal`, `flip`, `dense`.
  `MetricsPanel` keeps `compact` and gains optional `height` (px or 'fill'). `PainPanel` restyled, same text.
- **Target switch**: same exports, props, test ids and wording; restyled (native select kept for accessibility).
- **/built**: player card (jersey SVG in the profile store's colour with name and levels passed on the back, rank from rank.ts,
  XP in flip digits, progress to next rank, levels, chapters finished, caps, biggest measured win), impact log as a timeline with
  before/after scoreboard figures, Story (portfolio write unchanged) beside it, then every passed level per chapter with its live
  show-me. `impact.ts` gained `figures`, `at`, `metricFigures`, `headlineWin`; `phrases`/`summary` unchanged (phrases are kept as
  screen-reader text under the figures, which is what the existing test reads).
- Shared frame `ui/src/career/ToolPage.tsx`; pure helpers in `ui/src/career/tools/` (new files kept inside my own folder).
