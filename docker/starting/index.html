The floodlights are warming up

The game is being set up on your Mac. This page opens the game by itself the moment it is ready.

  1. Checking your Mac Docker, memory, disk space and ports. This takes a few seconds.
  2. Building the game The first start downloads images and builds the game: give it a few minutes. Later starts are quicker when nothing has changed.
  3. Starting the services The database, the engine and the screens come up. The first time it also loads the sample league, so give it about a minute.
  4. Ready The game opens here by itself.

Waiting for the start script. If you have not started the game yet, open a terminal in the Redis Quest folder and run ./scripts/start.

Total time so far: just started. Nothing here leaves your Mac.
