# Redis Quest: project context for coding sessions

**What:** local, story-driven Redis learning game for backend SDE1s. Design: `docs/PLAN.md`. Board:
`docs/BUILD.md`. Conventions for agents: `CLAUDE.md`.

**Architecture (short):** Docker Compose on the learner's Mac. Caddy proxy :3000 → `engine` (single
instance: levels, verifiers, progress, CLI proxy, load generator, log tail) and `app` (scalable: the
pre-built fantasy-cricket backend, loads learner code from `workspace/` into named slots). `runner`
calls learner functions directly for behavior tests. `redis:8` (JSON, Search, time series, Bloom built
in), `redis/redisinsight` on :5540, `postgres:16` as the deliberately slow legacy DB with an outbox
table for CDC. Chapter 5 compose profiles: crash, replica, sentinel, cluster (7100-7105).
