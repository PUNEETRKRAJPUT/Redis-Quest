## Recent decisions
- Next.js runs as its own compose service `ui` (standalone server, port 3100, 384m); Caddy sends `/api/*`,
  `/health`, `/ws` to the engine, `/app/*` to the app, the rest to `ui`. The engine no longer serves the UI.
- All game data stays client-side (store + engine API + one WebSocket). Routes are static shells; Cache
  Components, Partial Prefetching and `experimental.useOffline` are on.
- Agents must read the version-matched docs in `ui/node_modules/next/dist/docs/` (ui/AGENTS.md, ui/CLAUDE.md).
- Design language: "Night match" (`docs/design/EXPERIENCE.md`); Tailwind 4, tokens in `ui/src/design/`.
- The game stays Apple Silicon Mac-only (2026-11-19); the 10-day plan is parked, not cancelled.
